# ianbedard

Personal business site for Ian Bédard: bilingual (EN/FR), accessible websites and Shopify stores for small businesses in Ottawa–Gatineau.

Plain HTML, CSS and JavaScript with no build step, so it can be hosted as is on GitHub Pages.

## Structure

```
index.html                  English one-page site
fr/index.html               French one-page site
work/*.html                 English case studies
fr/realisations/*.html      French case studies
assets/css/style.css        All styles
assets/js/main.js           Mobile menu + contact form submit
assets/js/waves.js          Animated contour waves (add data-waves="top|bottom|both" to a dark section)
assets/img/                 Project screenshots and mockups
tools/                      Python scripts that generate the case studies, mockups and logo
```

## Placeholders to replace

Search the project for these and swap in the real values:

| Placeholder | Where | Replace with |
|---|---|---|
| `cal.com/YOUR-USERNAME/15min` | Home pages (hero + contact) | Your Cal.com or Calendly link |
| `YOUR_FORM_ID` | Contact forms | A [Formspree](https://formspree.io) form ID (free tier works) |

The email and LinkedIn in the case study footers come from `EMAIL` and `LINKEDIN` in `tools/build_case_studies.py`.

## Case studies

Case study pages are generated from the data in `tools/build_case_studies.py`:

```
python tools/build_case_studies.py
```

To add a live demo to a project, add `demo`, `password` and (optionally) `figma` to its entry, as Café Brume has, then rerun the script.
When you get real clients, add them to the top of the `P` list and move them first on the home pages' work grid.

Café Brume uses real screenshots of the live store (`assets/img/cafe-brume/`). The other concept mockups are generated by `python tools/build_mockups.py`. To switch a project to real screenshots, put them in `assets/img/<slug>/` and add a `shots` entry like Café Brume's.

## Font and logo

The font is **Evert PE** from Adobe Fonts (web project kit `vqa6miq`, loaded with `https://use.typekit.net/vqa6miq.css`). It needs an active Adobe subscription; if the kit stops loading, the site falls back to the system font.

The logo mark (`assets/img/logo-mark.svg`) is generated by `python tools/build_logo.py`: a sphere filled with 10 sunset ripple lines.

## Publishing with GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root.
